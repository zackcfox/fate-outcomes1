Welcome to Elderfield — Fate Roll Command (Version 2) 

This repository contains a custom StreamElements Twitch chat command with 30 possible fate outcomes.

The command is based on the game Welcome to Elderfield and was created specifically for @mochiigoblin's Twitch channel.

How It Works

The command randomly rolls one of 30 possible outcomes:

1A through 6E

Example:

@Username rolled a 3E and met their fate: You found a Tiny Coin Pouch! Gain 21g.
